# Program Konversi Suhu

## Deskripsi
Program sederhana menggunakan bahasa Go untuk mengubah suhu Celsius menjadi Fahrenheit dan Kelvin.

## Fitur
- Konversi Celsius ke Fahrenheit.
- Konversi Celsius ke Kelvin.
- Input suhu dari pengguna.

## Teknologi
- Bahasa Go
- Visual Studio Code
- Git dan GitHub

## Cara Menjalankan
Jalankan perintah:

go run main.go
